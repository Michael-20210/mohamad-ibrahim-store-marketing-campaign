# Mohamad Ibrahim Store - Digital Marketing Campaign (Project 2)

Angular ecommerce marketing project for **Mohamad Ibrahim Store**.

## Project 2 requirements implemented

- Existing ecommerce store extended for the marketing campaign.
- Product catalogue fetched from **Fake Store API** (`https://fakestoreapi.com/products`).
- Categories are derived from the API product data.
- Angular **SSR** is enabled for product/category routes.
- Angular **SSG / prerendering** is enabled for the root route.
- SEO configuration includes dynamic page titles, descriptions, keywords, Open Graph tags and robots.txt.
- Search, category filtering, product cards and cart interaction remain available.
- Mega Shopping Sale banner includes **Up to 60% off**, **Free shipping over $50**, **14 days**, and **Shop Now** CTA.
- Project is configured for Vercel using the Angular framework preset.

## Campaign details

- Campaign: **Mohamad Ibrahim Store Mega Shopping Sale**
- Promotion: **Up to 60% off**
- Free shipping: **Orders over $50**
- Duration: **14 days**
- Primary goal: **Increase Sales**
- CTA: **Shop Now**
